OptiCore
CLI

Una utilidad en Python para convertir PDF a Markdown, contar tokens y revisar archivos temporales desde un menú sencillo.

PDF a MarkdownConvierte documentos para hacerlos más fáciles de revisar y reutilizar.
Conteo de tokensConsulta de forma rápida el tamaño de tus textos para trabajar mejor con IA.
Archivos temporalesIdentifica y revisa archivos que ya no necesitas.
